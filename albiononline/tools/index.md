# Tools

- [download](https://github.com/epoiisa/download) — Command line tool for downloading Albion Online item and spell icons. Supports Windows & macOS/Linux.
- [Guild Manager](https://github.com/epoiisa/guild-manager) — Discord bot with character registration, member management, guild and alliance configuration, party signups, specialisation registration, re-gear management, guild accounts, applications and tickets, UTC time channel, temporary voice channel, bot message posting, and bot customisation.
